# Motivación / [Rationale](README.md) #

Principalmente, una fuente para uso interno (como forma de automatizar algunas tareas gráficas) y, a continuación, una forma de eludir la penalización de Google al acceder al sitio web. Después, una vez superadas un sinfín de críticas _de buena fe_, puede convertirse en código abierto. ¡El tiempo lo dirá!

### ¿Para qué sirve este repositorio? ###

* Resumen rápido
    - Creación de una fuente web para minimizar nuestro ancho de banda al acceder al sitio web [IMHICIHU](https://imhicihu.conicet.gov.ar/). 
* Versión 1.01

### ¿Cómo se configura? ###

* Resumen de la configuración
    - _En desarrollo_
* Configuración
    - [Fontforge](https://fontforge.github.io/en-US/downloads/)
* Dependencias
    - Sin dependencias
* Configuración de la base de datos
    - No se ha creado ni se creará ninguna base de datos para este proyecto
* Cómo ejecutar pruebas
    - Una vez que visites el sitio web [IMHICIHU](http://www.imhicihu-conicet.gob.ar/), el navegador descargará la fuente web en tu ordenador, por lo que, cuando vuelvas a visitarnos, se cargará más rápidamente
* Instrucciones de implementación
    - Una vez que esté disponible, solo tienes que descargarla desde nuestra sección «Descargas»
